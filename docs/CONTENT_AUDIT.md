# Аудит контента для Google Play Families (только список, ничего не менялось)

Дата: 2026-11-05. Скриншоты — `~/tails-shots/audit-*.png` (вне проекта).
Политика Families требует, чтобы контент был уместен для детей: без сексуализированных/полураздетых
фигур, без реалистичного насилия и крови. Ниже — что может быть сочтено неподходящим.

**Обновление 2026-11-08 (пункты 1–2):** на «Танцовщице» теперь джинсы от края футболки до тапок — дорисованы на текстуре
обеих моделей (`tools/dancer-outfit.mjs`, проверка — `tools/model-views.html`). Из бегущей модели убраны клипы
«Crawl», «Crawl_All_Fours», «Get_Down_And_Up». Персонажем игрока она не выбирается с версии 1.9.

Не вызывает вопросов: замок `assets/castle/stage1..4.glb`, привидения (процедурные, улыбающиеся),
домик, деревья, плиты. Тексты и голос — дружелюбные («Ой! Хвостик утащили!»), без угроз.
Слово «тени» и тёмная тонировка врагов — мягко, не пугающе.

Что можно сделать (не делалось, по заданию только список): одеть модель Tiny Dancer (штаны/юбка) или
заменить её на стилизованного персонажа; не тонировать всё тело целиком (тонировать только футболку);
удалить из файла персонажа неиспользуемые клипы ползания; для маскота — убрать татуировки.
