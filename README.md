# Хвосты — башенная защита для детей 4–8 лет

Отдельный проект на основе игры из `~/infra/alisa` (three.js, без сборки): три карты уровней,
командная игра до 4 игроков, бегающий персонаж и редактор своих уровней.

## Запуск — одной командой

```bash
cd ~/infra/tails-game
npm install          # ws (сервер), для проверок — puppeteer-core, gltf-transform, meshoptimizer
npm start            # http://127.0.0.1:8795/  — и статика, и комнаты командной игры (WebSocket /ws)
```

`PORT=…` и `HOST=…` меняют адрес (`HOST=0.0.0.0` — чтобы зайти с телефона в той же Wi-Fi сети).
Для одиночной игры сервер мультиплеера не нужен, но удобнее запускать всё одним `npm start`.

## Карты и уровни

* **🎀 Набережная** — 10 мест Герцег-Нови из исходной игры: Топла, Игало, Савина, Шкверская лестница,
  Пет Даница, Стари град, Белависта, Форте-Маре, Мамула, Канли-Кула.
* **🏰 Замок** — 5 залов, башня игрока — замок, растёт стадиями 1→4 (`assets/castle/stage1..4.glb`),
  привидений с каждым залом больше (30→50 %): Ворота, Ров, Подъёмный мост, Двор с колодцем, Тронный зал.

Прогресс отдельный для каждой карты: пройденный уровень открывает следующий, звёзды — по оставшимся
ленточкам (5 → ⭐⭐⭐, 3–4 → ⭐⭐, 1–2 → ⭐).

## Командная игра

* Лобби: «Создать» (карта, уровень, открытая или только по коду) → код из 4 символов без похожих
  `0/O/1/I`. Друзья входят по коду или кнопкой «Присоединиться» в списке открытых игр
  (карта, уровень, игроки N/4, «ждут»/«идёт»). Можно войти и в уже идущую игру, пока игроков < 4.
* Модель — **ведущий (хост) считает игру**: в его браузере крутится `sim.js`, ~12 раз в секунду
  остальным уходит компактный снимок (массивы, округлённые числа, ~1–2 КБ). Участники присылают действия
  (построить, подрасти, домой, волна, танцуем, позиция персонажа) — ведущий проверяет и применяет.
* Общий домик и волны; у каждого свои ракушки (награду за тень получают все) и свои подружки — цветное
  кольцо и значок с ником над каждой. Растить и отправлять домой можно только своих.
* Ушёл ведущий (кнопка «Домой» — сразу, закрыл вкладку — через 8 с) — ведущим становится следующий,
  игра продолжается с последнего снимка. Ушли все — комната удаляется.

## Бегающий персонаж

На карте «Замок» и в своих уровнях — персонаж (`assets/characters/tiny-dancer.glb`):
WASD/стрелки или экранный джойстик на телефоне, «Строить тут» (E) — меню ближайшей плиты, прыжок — пробел.
Шаг/бег смешиваются по скорости; при стройке — «молоток», на танце — танец, на победе — «ура».
Камера следует за персонажем, 🗺 — общий вид. В командной игре видно всех: позиция идёт через ведущего ~10 раз/с.

Анимации перенесены скриптом `tools/retarget-anims.mjs` с модели на скелете Mixamo (проверка по общему
клипу: средняя ошибка 11° против 19° без поправки поз покоя). Исходник анимаций (17 МБ) в проект не входит.

## Свои уровни

`editor.html`: персонаж бегает по полю 15×13 и ставит инструментом (или тапом по клетке) дорогу, плиты,
старт теней (1–2), домик. Проверка на лету: есть ли дорога от каждого старта до домика (A*).
Число волн, сложность, тема (набережная/замок). «Сохранить» → «Мои уровни» (localStorage),
«Код» — короткая строка для друга, «Вставить код» — загрузить. Свой уровень можно играть одному и выбрать
для командной игры: код уровня ведущий передаёт через комнату, сервер его проверяет.

## Проверки

```bash
npm start &                       # сервер
npm run check:levels              # раскладки уровней
npm run balance                   # сводка баланса; npm run balance:md — обновить docs/BALANCE.md
npm run test:e2e                  # 4 игрока в headless Chromium (/snap/bin/chromium)
node tools/e2e-editor.mjs         # редактор → сохранить → сыграть; печатает код уровня
node tools/e2e.mjs --custom КОД   # командная игра на своём уровне
```

## Выкладка

Нужен один процесс Node ≥ 18 (`npm ci --omit=dev && PORT=8795 node server/index.js`) за обратным прокси
с поддержкой WebSocket (nginx: `proxy_http_version 1.1; proxy_set_header Upgrade $http_upgrade;
proxy_set_header Connection "upgrade";` на `/ws`), HTTPS обязателен для телефонов (wss://).
Состояние комнат — в памяти процесса: один процесс, без кластера. Подробности — в ответе/отчёте.

## iOS-приложение

`ios/` — то же, что Android-приложение: WKWebView во весь экран, только горизонтально, iOS 16.4+ (нужен importmap), iPhone и iPad.
Страницы открываются с `tails://app/…` (`BundleSchemeHandler.swift` отдаёт файлы из `Tails.app/www`), поэтому модули,
fetch моделей и localStorage работают как на сайте; `src/net.js` по схеме `tails:` понимает, что он в приложении,
и ходит на `spacecode.business/tails/play`. Пакет `business.spacecode.tails`, версия — из `android/version.properties`.

* `ios/run_sim.sh ["iPhone 17 Pro"]` — собрать и запустить в симуляторе; в выводе — console.* и ошибки страницы.
  В Debug можно открыть сразу нужную страницу: `xcrun simctl launch <udid> business.spacecode.tails -page 'race.html?level=1'`.
* `TEAM=<Team ID> ios/build.sh` — IPA для App Store → `ios/dist/tails-<CODE>.ipa`.
* `ios/screenshots.sh ПАПКА` — снимки для App Store (iPhone 6,9″ и iPad 13″): сцены расставляет отладочный `-js '…'`
  (скрипт на каждой странице, только в Debug). Пакет для публикации — `../ios_release/`.
* Игру в приложение копирует `ios/sync_web.sh` на каждой сборке (фаза «Sync web game»): после правок в вебе достаточно пересобрать.

## Персонаж, команда, свои уровни (ноябрь 2026)
- **Персонаж**: выбирается в профиле (`profile.html`): модель и цвет поверх текстуры. Бегает на всех картах, кроме Набережной в одиночку.
- **Распрыжка**: прыжок сразу при приземлении сохраняет и увеличивает скорость (до ×2.4), в воздухе ею можно рулить.
- **Бой**: удар стоит жизнь; убил персонаж — жизни без денег; убила башня — деньги. Числа и командные правила — `docs/BALANCE.md`.
- **Редактор**: можно выбрать защитников (в том числе замок) и количество привидений.
- Проверка правил без графики: `node tools/combat-test.mjs`; командная игра в браузере: `node tools/e2e.mjs`.

## Управление пальцами (1.4.0)
- Кнопки боя срабатывают в момент касания: браузер не присылает click второму пальцу, поэтому раньше нельзя было прыгать на бегу.
- Касание холста в 36 px от кнопок не двигает камеру; рядом с «Прыжком», «Ударом», «Строить тут» нажимает их, рядом с «Волной» ничего не запускает.
- В левой нижней части экрана джойстик появляется под пальцем.
- Редактор на телефоне: поле целиком, один палец рисует, два — камера, настройки в панели «Ещё», есть шаг назад.
- Проверка настоящими касаниями: `node tools/e2e-touch.mjs`.

## Гонка в космосе (1.5.0)
- Карта «Гонка»: `race.html?level=N` один против трёх ботов, `race.html?room=КОД` до четырёх игроков через обычную комнату в лобби, без ботов.
- Персонажи летят в прозрачном витом тоннеле, как самолёты: свободно смещаются в сечении, наклоняются в вираж.
- Разгон плавный. Сила на вираже растёт с квадратом скорости, сцепление с ней падает, поэтому чем быстрее, тем сильнее заносит. Руль и тормоз: джойстик под пальцем слева, тормоз справа; на компьютере WASD/стрелки и пробел.
- Преграды: стена с проходом, половина сечения, вращающаяся балка, астероиды. Удар сбрасывает скорость, стенка её подтачивает, кольца-ускорители добавляют.
- `src/race-sim.js` — трасса и физика без графики, `src/race.js` — сцена, боты, сеть. Каждый считает своего персонажа сам, ведущий рассылает позиции и порядок финиша; сервер прежний, ему нужны только новые уровни из `levels.js`.
- Проверки: `node tools/race-test.mjs` без браузера, `node tools/e2e-race.mjs` в браузере.


## Вентиляторы вместо стрельбы (1.13.0)
- В гонке больше нет стрельбы и грязевых бомб: ни у игрока (кнопки «Огонь», клавиш F/B), ни у ботов.
- В редакторе трасс два новых блока: **🌬️ Попутный ветер** и **🌀 Встречный ветер** — вентилятор на всё сечение тоннеля. Пролетел — 1,6 с дует: попутный разгоняет до 135 % обычного максимума, встречный тормозит до 35 %. Цифры — `WIND` в `src/race-sim.js`.
- В коде трассы это типы блоков 9 и 10 (`w`/`v` в текстовых раскладках). Трассы с вентиляторами старые версии не откроют.
- Проверки: `node tools/race-design-test.mjs` (ветер разгоняет/тормозит, бот пролетает, код сохраняется), `node tools/e2e-race.mjs` (стрельбы нет).
